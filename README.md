# SHA-256
Реализация алгоритма SHA-256 на Python.

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)
![Cryptography](https://img.shields.io/badge/Cryptography-Hash-green.svg)

## О проекте
SHA-256 - это чистая реализация криптографического хеш-алгоритма SHA-256 на Python для образовательных целей, демонстрирующая принципы работы хеш-функций, битовых операций и обработки данных на низком уровне.

### Возможности
- Полная реализация алгоритма SHA-256 без использования внешних библиотек
- Поддержка строк и байтовых данных на входе
- Пошаговая обработка данных с буферизацией
- Правильное дополнение сообщения (padding) согласно стандарту
- Методы `update()`, `digest()`, `hexdigest()` как в стандартном hashlib
- Функции быстрого хеширования: `sha256()` и `sha256_hex()`
- Встроенные константы инициализации (H0) и раундовые константы (K)
- Реализация всех битовых операций: циклический сдвиг, XOR, AND, NOT
- Простая и понятная структура кода с подробными комментариями

### Пример использования
```python
from sha256 import sha256_hex

# Хеширование строки
hash_value = sha256_hex("Hello")
print(hash_value)  # 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
```
